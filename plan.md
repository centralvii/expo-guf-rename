# План разработки проекта: Пакетное переименование .guf файлов

1. **Инициализация и установка зависимостей**
   - Установить необходимые пакеты: `jszip`, `file-saver`, `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities`.
   - Установить типы для TypeScript: `@types/file-saver`.
   - Настроить базовую структуру директорий (`src/types`, `src/utils`, `src/components`, `src/services`).

2. **Создание базовых типов и утилит**
   - Описать тип `FileRow`.
   - Написать функцию `cleanName` для очистки исходного имени файла.
   - Написать template engine для обработки шаблона.
   - Написать функции валидации (проверка недопустимых символов, дублей и т.д.) и форматирования индекса.

3. **Реализация ZIP-логики**
   - Создать сервис с логикой чтения ZIP (извлечение всех файлов с сохранением Blob).
   - Создать сервис для упаковки обработанных файлов обратно в ZIP-архив.

4. **Создание интерфейса и компонентов (UI)**
   - Настроить современный, чистый и приятный дизайн (CSS).
   - Зона загрузки файлов.
   - Панель настроек шаблона и массового заполнения полей.
   - Список файлов.

5. **Реализация основной логики приложения**
   - Интегрировать Drag-and-Drop (на базе `@dnd-kit`) в список файлов для изменения порядка.
   - Связать состояние, пересчет шаблонов в реальном времени, превью.
   - Добавить вывод ошибок перед экспортом.

6. **Тестирование и финальная доработка (Полировка)**
   - Проверить стабильность всех функций.
   - Добавить анимации и отзывчивость интерфейса.
   - Удостовериться, что проект готов к продакшену.
